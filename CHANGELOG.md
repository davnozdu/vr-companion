# Изменения

## v1.2

- Список очков сохранялся в формате, который модуль не понимал: имя
  устройства попадало в строку без комментария, и после первого же
  «Сохранить» модуль перестал бы опознавать очки. Теперь имя пишется
  после `#`, а строки, не похожие на VID:PID, отбрасываются
- Сохранённые очки в списке показываются с именем, а не одним
  идентификатором

## v1.1

- Отсутствие root больше не выглядит как отсутствие модуля: причины
  разделены и подсказки к ним разные
- Права root перепроверяются при каждом возврате в приложение — выданные
  на ходу подхватываются сразу
- Своя иконка вместо скопированной у VR Monitor: янтарный фон и гарнитура
  с микрофоном, в списке приложений теперь различимы

## v1.0

Первый выпуск: плитка в шторке, экран состояния, список очков,
проверка обновлений по релизам GitHub.
