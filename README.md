# VR Companion

Приложение-компаньон для VR-очков. Сейчас умеет переключать режим очков —
гарнитура или монитор — плиткой в шторке. Дальше вырастет до съёмки фото
и видео с камеры очков и разговора с LLM.

Собрано под **OnePlus 15 (Android 16, KernelSU Next)** и очки **XREAL One Pro**.

---

## Что делает

| | |
|---|---|
| **Плитка в шторке** | одно касание переключает гарнитуру и монитор |
| **Экран приложения** | текущий режим, какие очки найдены, есть ли звук и работает ли демон |
| **Список очков** | отметить свои устройства из числа подключённых |
| **Обновления** | проверяются по релизам GitHub при каждом открытии |

## Зачем плитка

Переключаться приходится часто: сел смотреть фильм — нужен монитор, пошёл
гулять — нужна гарнитура. Лезть ради этого в терминал за `vr-mode` неудобно,
а плитка доступна из любого места двумя касаниями.

Добавляется один раз: шторка → карандаш → перетащить «Режим очков» наверх.

## Требуется модуль

Приложение само по себе ничего не переключает. Всю работу делает модуль
[VR Headset Mode](https://github.com/davnozdu/vr-headset-mode): он владеет
DisplayPort, следит за очками и держит режим. Приложение — только удобная
оболочка над его командой `vr-mode`.

Так сделано намеренно. Если бы приложение писало в sysfs само, оно и демон
модуля дёргали бы один и тот же узел, и состояние зависело бы от того, кто
успел раньше.

Без модуля приложение честно скажет, что переключать нечем.

## Root

Нужен: чтение `/data/adb` и вызов `vr-mode` доступны только root. Выдайте
разрешение один раз в KernelSU Manager → SuperUser.

## Установка

Скачайте APK из [Releases](https://github.com/davnozdu/vr-companion/releases).

Все релизы подписаны одним ключом, поэтому обновления ставятся поверх
и не требуют удаления. Разрешение root при этом сохраняется: в KernelSU
оно привязано к UID, а UID не меняется, пока подпись та же.

## Разрешения

Только `INTERNET` — для проверки обновлений по релизам GitHub. Ни камеры,
ни микрофона, ни доступа к файлам приложение пока не просит.

## Планы

- съёмка фото и видео с камеры XREAL Eye
- отправка кадра в LLM и озвучивание ответа через динамики очков
- голосовой запрос с микрофонов очков

Протокол камеры уже разобран и описан в
[xrprobe/PROTOCOL.md](https://github.com/davnozdu/xrprobe/blob/main/PROTOCOL.md).
